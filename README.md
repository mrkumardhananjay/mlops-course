# MLOps Course

A complete, self-contained course in Machine Learning Operations, taught at an undergraduate level. One project runs the whole semester: a delivery time predictor that travels from a notebook to a versioned, tracked, served, containerised, automated and monitored service.

Nothing here needs a GPU. Every practical is designed for an ordinary laptop with 8 GB of memory.

## What is here

| Folder | Contents |
|---|---|
| `lectures/` | Lecture handouts, one per lecture. Each carries the full content, worked examples, assignment questions, a self check section, a glossary and a short reading programme |
| `practicals/` | Laboratory practicals, one per session, each building on the last |
| `course/` | The course handout and the laboratory setup guide |
| `releases/` | Compiled PDFs, ready to distribute |

## The arc

The project moves one step per session:

reproducible environment, versioned data, a tested package, tracked experiments, a served model, a container, a composed stack, an automated pipeline, monitoring.

Nothing is thrown away. Every step assumes the one before it.

## Who this is for

Students who can train a model and cannot yet hand it to a stranger and have it keep working. Instructors looking for a course that teaches the engineering around the model rather than only the model.

## Approach

Every claim is sourced. Case studies cite primary sources rather than press coverage. Every score quoted was measured on the course dataset rather than copied from a book. Tooling is deliberately fixed and minimal, one tool per job, because the discipline is what transfers and the tools will change.
